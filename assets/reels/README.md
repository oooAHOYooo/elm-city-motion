# Reel Video Assets (`assets/reels/`)

Drop your long video reels or video clips into this folder.

### Recommended format:
- Format: `.mp4` (H.264 video codec)
- Frame rate: 24 fps (cinematic film cadence)
- Audio: Silent / stripped (ambient visual stream)

### Git Status:
All video files (`.mp4`, `.mov`, `.webm`, `.m4v`, etc.) placed in this directory are automatically ignored by `.gitignore`, so your repository stays lightweight and fast.
